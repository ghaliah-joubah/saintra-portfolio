# الخطة التنفيذية الموسعة والمواصفات المعمارية للوحة التحكم المباشرة (SAINTRA Admin Dashboard & Local CMS Specification)

---

## 1. 📌 الهدف ونطاق المشروع المستقبلي

تحويل النظام الحالي من قراءة ملفات نصية ثابتة إلى **منظومة إدارة محتوى رقمية ديناميكية ومستقلة (Local & VPS-Ready CMS)** تتيح لك تعديل كافة بيانات وبيانات التواصل والخدمات والمشاريع والترجمات والنصوص فورياً وبطريقة بصرية دون الحاجة لكتابة كود أو تعديل يدوي، مع ضمان عمل المنظومة **لوكال على جهازك** وجاهزيتها للتثبيت المباشر على **سيرفر VPS**.

---

## 2. 🏛️ المعمارية التقنية واستراتيجية البيئتين (Dual-Adapter Architecture)

لضمان تشغيل لوحة التحكم بكفاءة متناهية وبدون تعقيدات في البيئتين (المحلية وعلى سيرفر الـ VPS):

```
                                 ┌─────────────────────────────────┐
                                 │   Admin Dashboard UI           │
                                 │   (/admin/* Views)             │
                                 └────────────────┬────────────────┘
                                                  │
                                                  ▼
                                 ┌─────────────────────────────────┐
                                 │   Data Persistence Service      │
                                 │   (src/services/dataService.ts) │
                                 └────────┬────────────────┬───────┘
                                          │                │
                      ┌───────────────────┘                └───────────────────┐
                      ▼                                                        ▼
      ┌──────────────────────────────┐                         ┌──────────────────────────────┐
      │  Local Dev Adapter           │                         │  VPS / Production Adapter    │
      │  (Vite Middleware Plugin)    │                         │  (Express Static API / JSON) │
      └──────────────┬───────────────┘                         └──────────────┬───────────────┘
                     │                                                        │
                     ▼                                                        ▼
      ┌──────────────────────────────┐                         ┌──────────────────────────────┐
      │  src/data/*.json (On Disk)   │                         │  dist/data/*.json & Server   │
      └──────────────────────────────┘                         └──────────────────────────────┘
```

### أ. في بيئة التطوير المحلية (Local Development Mode):
- يعتمد خادم Vite على بلجن خفيف مخصص (`vite-plugin-local-cms`) يتم إضافته في `vite.config.ts`.
- عند التعديل في لوحة التحكم، ترسل النماذج طلب حفظ إلى `/api/admin/save-data`.
- يقوم البلجن مباشرة بكتابة وتحديث ملفات `JSON` في المجلد المصدري `src/data/*.json` على قرص الجهاز مباشرة، مما يتيح لك تسجيل التعديلات في Git فورياً.

### ب. في بيئة السيرفر المستقل (VPS / Production Mode):
- يوفر النظام خيارين مرنين للنشر على سيرفر VPS:
  1. **الخيار الموصى به (Nginx + Node Express Micro-Server)**: يتم تزويد المشروع بسيرفر خفيف جداً (`server/index.js` لا يتعدى 40 سطر كود) يعمل بواسطة `PM2` ليسمح بتعديل وحفظ ملفات الـ JSON على السيرفر مباشرة وحفظها على الديسك.
  2. **الخيار الاستاتيكي النقائي (Pure Static Nginx)**: في حال عدم رغبتك في تشغيل Node على السيرفر، توفر لوحة التحكم زر **"تصدير النسخة الاحتياطية (Export JSON Backup)"** واستيرادها أو رفعه بضغطة زر.

## 3. 📂 تنظيم هيكلية البيانات والـ Typescript Specs

سيتم تحويل البيانات الحالية إلى ملفات `JSON` حقيقية نظيفة، مع إنشاء واجهات TypeScript دقيقة في `src/types/data.ts`:

* **`src/data/company.json`**: بيانات الشركة، الرؤية، الرسالة، القيم، بيانات الاتصال الموثقة، الساعات، الإحصائيات، ومواقع الفروع.
* **`src/data/services.json`**: جميع الخدمات، التصنيفات، حقول What's Included، خطوات العمل Our Process، وروابط فيديو الشرح.
* **`src/data/projects.json`**: جميع المشاريع، التصنيفات، معارض الصور، التقنيات، سنة الإنجاز، حجم الفريق، الروابط المباشرة، وعلاقات `serviceIds`.
* **`src/data/siteCopy.json`**: النصوص الثابتة، عناوين الواجهات، الترجمات (AR/EN) للفوتر والناڤ بار والأزرار.
* **`src/data/authConfig.json`**: التشفير المحلي لكلمة مرور لوحة التحكم وإعدادات الجلسة.

## 4. 🎨 واجهات لوحة التحكم التفصيلية (`src/views/admin/`)

سيتم بناء لوحة تحكم عصرية كاملة في المسار `/admin` بهوية بصرية متناسقة مع الموقع (Glassmorphic Dark Theme) وتشمل الواجهات التالية:

### 1. **تسجيل الدخول والحماية (`/admin/login`)**:
   - حماية المسارات برابط حماية تلقائي (`router.beforeEach`).
   - تسجيل الدخول بواسطة كلمة مرور محلية مشفرة محلياً (مع إمكانية تغيير كلمة المرور من إعدادات اللوحة).

2. **لوحة النظرة العامة (`/admin/dashboard`)**:
   - مؤشرات سريعة لإجمالي المشاريع والخدمات وزيارات الموقع المباشرة.
   - حالة حفظ البيانات والتحديثات الأخيرة.
   - زر **"تصدير نسخة احتياطية لكافة البيانات (Full Backup JSON)"** وزر **"استعادة نسخة سابقاً"**.

3. **إدارة بيانات الشركة والإحصائيات (`/admin/company`)**:
   - محررات نصوص باللغتين العربية والإنجليزية لـ: اسم الشركة، القصة، الرؤية، الرسالة.
   - محرر القيم الجوهرية (إضافة/تعديل/حذف قيمة).
   - محرر الإحصائيات (إضافة/تعديل القيم والمسميات واللاحقات مثل `+` و `%`).
   - محرر بيانات التواصل المباشرة (الإيميل، رقم الواتساب، العنوان، وساعات العمل).

4. **إدارة الخدمات المتقدمة (`/admin/services`)**:
   - جدول تفاعلي بالخدمات الحالية مع خيارات (إضافة خدمة جديدة، تعديل، حذف، تغيير الترتيب).
   - محرر مكونات "ما تتضمنه الخدمة (What's Included)".
   - محرر خطتنا للعمل (Our Process) بالخطوات والأرقام.
   - منتقي صور ومختبر روابط فيديو يوتيوب المباشر.

5. **إدارة المشاريع والأعمال (`/admin/projects`)**:
   - إدارة كاملة للمشاريع (CRUD).
   - محرر معرض الصور (إضافة روابط/رفع صور للمشروع).
   - محرر الوسوم والتقنيات (Tags input) للتقنيات المستخدمة.
   - محرر متعدد لتحديد الخدمات ذات الصلة (`serviceIds`) لربط المشروع بالخدمات تلقائياً.
   - زر تفعيل/إلغاء زر "زيارة المشروع المباشر".

6. **إدارة النصوص الثابتة والترجمات (`/admin/site-copy`)**:
   - جدول منظم يتيح تعديل أي نص في القوائم والأزرار والعناوين باللغتين جنباً إلى جنب مع حفظ فوري.

7. **إدارة الوسائط والصور (`/admin/media`)**:
   - متصفح صور محلية يتيح رفع الصور الجديدة مباشرة إلى مجلد `public/images/` للحصول على رابطها واستخدامها في المشاريع والخدمات.

## 5. 🛠️ خطة التنفيذ الميدانية دفعة واحدة (One-Run Master Implementation Steps)

عند إشارة البدء المستقبلي، سأقوم بتنفيذ الخطوات المحددة التالية بأسلوب متسلسل ومنسق دون انقطاع:

### الخطوة 1: تهيئة ملفات JSON والـ Types Definitions
- نقل البيانات الحالية إلى `src/data/*.json`.
- إنشاء ملف الواجهات البرمجية `src/types/data.ts`.
- تحديث الـ Composables والخدمات لقراءة البيانات محلياً مع التخزين المؤقت (Caching).

### الخطوة 2: بناء خادم الحفظ المحلي (Vite Plugin & Micro-Express Server)
- كتابة `vite-plugin-local-cms` في `vite.config.ts` للعمل في بيئة `npm run dev`.
- كتابة خادم Node المستقل في `server/index.js` للعمل على سيرفر الـ VPS مع تشفير الطلبات والتأكد من الصلاحيات.

### الخطوة 3: تطوير مكونات ولوحة التحكم وتوجيهات الحماية
- إنشاء `src/components/admin/AdminLayout.vue` مع الشريط الجانبي والهيدر وأزرار الحفظ.
- إنشاء جميع الواجهات الفرعية في `src/views/admin/`.
- إعداد حارس المسارات (Route Guard) لمنع الوصول غير المصرح به لـ `/admin/*`.

### الخطوة 4: تطوير خادم ونصوص النشر للـ VPS (`docs/DEPLOYMENT_GUIDE.md`)
- إنشاء ملف إعدادات Nginx المعتمد (`nginx.conf.template`) يدعم الـ SPA وتوليد خوادم التخزين المؤقت وتأمين لوحة التحكم.
- إنشاء ملف إعدادات `ecosystem.config.js` لتشغيل خادم البيانات تلقائياً بـ `PM2` على سيرفر الـ VPS.

### الخطوة 5: الاختبار والتثبيت والرفع
- تشغيل واختبار جميع العمليات محلياً: إضافة مشروع جديد، تعديل خدمة، تغيير نص، والتأكد من انعاكشها الفوري على الموقع العام.
- تشغيل بناء الإنتاج (`npm run build`) واجتياز الاختبارات.
- إجراء Commit منظم ورفع التغييرات مباشرة لفرع `dev` وفرع `main` على GitLab.

## 6. 📄 الملفات المخطط إنشاؤها وتعديلها

| الملف | الوصف والوظيفة |
| :--- | :--- |
| `src/data/*.json` | ملفات البيانات الديناميكية الشاملة المجهزة للتعديل المباشر. |

| `docs/DEPLOYMENT_GUIDE.md` | دليل إرشادي خطوة بخطوة لرفع وتشغيل الموقع ولوحة التحكم على أي سيرفر VPS (مثل Ubuntu / Nginx / Node / PM2). |
